# 三国杀助手功能清单

保留浏览器油猴脚本和本地 Electron 微端，两端共用游戏辅助代码。助手不再采集、自动填充或保存游戏密码，不需要助手账号；进入游戏仍使用游戏平台自己的登录流程。

下表的“默认”指全新配置。旧配置可能保留不同开关状态。“已接入”表示当前启动代码会安装该功能，不代表已经在最新游戏版本中实测通过。

## 双端支持

| 形态 | 使用方式 | 功能与差异 |
| --- | --- | --- |
| 浏览器插件 | 安装到 Tampermonkey 等支持 userscript 的扩展中 | 加载游戏页面后注入面板；配置保存在该站点浏览器存储中；外链由浏览器打开。仓库没有独立的 Chrome 扩展 manifest。 |
| 本地微端 | Electron 壳加载游戏并注入助手脚本 | 使用相同的游戏辅助模块；另外提供窗口控制、本地文件存储和原生报告窗口等桥接。发布版支持实例配置隔离、部分设置跨实例共享。 |

源码入口：[浏览器](../src/entries/userscript.ts)、[微端](../src/entries/electron.ts)、[共用功能装配](../src/core/bootstrap.ts)。微端目前仍存在高权限网页配置，详见[安全审计](SECURITY_AUDIT.md)。

## 对局信息与记牌

| 功能 | 具体作用 | 默认或触发方式 |
| --- | --- | --- |
| 明牌展示 | 在其他武将牌下展示已经跟踪到的已知牌，随卡牌移动更新位置与来源 | 开启 |
| 局内牌堆入口 | 在游戏界面提供最近用牌、牌堆顶、牌堆底及弃牌查看入口 | 开启 |
| 本回合弃牌记录 | 在助手常规页展示本回合进入弃牌区的牌 | 开启 |
| 弃牌排序 | 按花色、类型、点数的不同优先顺序排列 | 默认花色→类型→点数 |
| 最近用牌 | 记录最近使用的牌，支持当前模式和按玩家模式 | 默认当前模式 |
| 卡牌来源标签 | 给自己的手牌添加来源等追踪标签 | 开启 |
| 回合状态 | 显示当前阶段、当前行动角色剩余出杀次数；折叠面板也保留简略信息 | 已接入 |
| 出牌倒计时 | 在游戏原有进度条上叠加剩余秒数 | 开启 |
| 人机提示 | 根据账号编号及游戏机器人标记区分真人、普通人机与其他高编号角色 | 已接入；属于代码规则判断 |
| 特定身份模式提示 | 在身份演武的自选身份、自选反贼、自选主忠模式中，按房间座位顺序推断并显示身份 | 对应模式触发；并非所有模式通用 |

明牌与牌堆信息依赖客户端收到的数据及移动记录，不能理解为保证看到所有隐藏手牌。相关代码：[明牌](../src/features/mingpai)、[记牌](../src/features/deck-record)、[最近用牌](../src/features/recent-cards)、[回合状态](../src/features/turn-status)。

## 操作便利功能

| 功能 | 具体作用 | 默认或触发方式 |
| --- | --- | --- |
| 扩展理牌 | 按类型、花色或点数整理手牌；长按拖动按钮、双击锁定排序方式 | 开启；初始不锁定 |
| 选牌工具 | 为选牌窗口添加全选、反选、快速选择，并遵守可选数量限制 | 选牌窗口出现时接入 |
| 铁索重铸 | 在允许重铸、没有选择目标时，让确定操作转入重铸流程 | 对应状态触发 |
| 背包搜索 | 给原生背包添加关键词搜索与本地列表过滤 | 打开背包时接入 |
| 将池搜索 | 给模式将池窗口添加关键词搜索 | 打开对应将池窗口时接入 |
| 密码房过滤 | 在经典房间列表隐藏带密码的房间 | 默认关闭；设置入口在相关房间控制器中 |
| 清除红点 | 手动清理任务、活动等界面上的红点 | 工具页按钮 |

“密码房过滤”中的密码是游戏房间口令，与登录密码管理无关。

## 技能计算与提示

以下技能面板由当前技能定义表接入，按本局技能、座位及事件显示；没有独立的统一默认开关。部分只对自己显示，部分要发动技能后才出现。

| 技能 | 提示内容 |
| --- | --- |
| 权变 | 记录花色使用序列，展示相关已知牌 |
| 渐营 | 展示相关花色序列，辅助查看连续用牌条件 |
| 宴戏 | 根据已知候选牌、手牌区域和牌堆位置推断来源；无法确定时显示未知 |
| 周旋 | 自己拥有技能时展示相关结果提示 |
| 严教 | 计算点数和相同的分组方案 |
| 资援及界资援 | 计算手牌点数和为 13 的组合，仅自己的技能面板显示 |
| 称象及界称象 | 技能发动后列出点数和不超过 13 的取牌组合，界版优先考虑和为 13 |
| 易城 | 计算手牌与亮出牌之间可行的点数交换方案 |
| 双雄 | 对接入的技能版本统计红黑牌数量，给出颜色提示，仅自己显示 |
| 吉占 | 统计大于、小于、等于当前点数的候选牌数量，给出猜大小提示 |
| 和衷 | 按候选牌点数与类别统计给出提示 |
| 权道 | 统计自己的杀和普通锦囊数量 |

来源：[技能定义](../src/features/skill-assist/skill-definitions.ts)、[点数计算](../src/features/skill-assist/point-calculators.ts)、[统计提示](../src/features/skill-assist/panel-texts.ts)。乱击的定义已被注释停用，不属于当前可用技能面板。

## 自动领取

总开关默认关闭。开启后，控制器在登录、对局结束、跨天及开关变化等时机调度任务、活动、签到和福利领取，也包含砍树、敲鼓等点击流程。

| 可排除的项目 | 默认 |
| --- | --- |
| 酒馆任务与进度同步 | 跳过 |
| 邮件附件 | 跳过 |
| 每日免费武将包 | 跳过 |
| 签到体验卡 | 跳过 |
| 含抵价券的奖励 | 跳过 |
| 含欢乐豆的奖励及相关免费领取 | 跳过 |

“勾选跳过”表示不领取该类内容。具体活动取决于游戏配置和当前活动窗口，不应理解为覆盖以后新增的全部活动。来源：[设置](../src/features/auto-task/auto-task-settings.ts)、[调度器](../src/features/auto-task/auto-task-controller.ts)、[执行流程](../src/features/auto-task/auto-task-runner.ts)。

## 个人版已处理的功能

| 项目 | 当前处理 |
| --- | --- |
| 账号密码管理器 | 删除密码读取、自动填充、保存和共享 IPC；浏览器、微端辅助代码均保留 |
| 历史密码数据 | 新版微端访问对应存储时清理旧助手密码字段和旧账号列表，页面 preload 清理旧密码 localStorage 键；不扫描磁盘备份 |

| 原作者自动更新 | 删除微端主进程更新入口及旧 updater 实现；油猴禁用远程更新并使用个人 namespace |
| 在线礼包码自动兑换 | 移除启动注册，源码保留但不再自动运行 |
| 面板远程版本检查 | 已停用网络检查；旧版更新界面和手动下载链接暂留 |

这些改动只有在重新生成并安装个人版后才会影响实际使用的助手。游戏平台自身的 Cookie、登录会话和浏览器密码管理不由本助手控制。自动化行为与账号处罚风险不能由本次源码检查排除。
