# 安全审计与个人版改造记录

本次为静态源码审计，没有安装依赖、启动游戏、编译或执行安装/更新脚本。补充执行了隔离临时目录中的存储清理测试和静态回归检查。结论仅适用于已检查的源码与调用路径，不能证明发行包、第三方依赖、旧混淆脚本或远端服务安全。

## 结论

没有找到足以确认当前可读源码主动盗号或植入系统木马的证据。但原代码有明确的账号与系统安全风险，不能直接认定安全。

## 审计边界

- 当前仓库没有找到独立管理后台服务、用户注册服务或服务端鉴权项目。README 提到的门户和服务端是仓库外的相邻项目，本次不可据此评价其安全性。
- 还检查了入口、Vite 配置、发布/安装脚本、网络调用、游戏运行时补丁及依赖清单。尚未逐行证明所有游戏功能正确安全，没有做依赖漏洞数据库或依赖包内容审计。
- 配置和皮肤功能仍会访问游戏资源。功能本身也会修改运行时和调用游戏协议。账号处罚风险取决于游戏规则，本次未验证规则，不能保证账号不受处罚。
- 本次没有直接读取或修改本机已安装助手的数据。新版微端会在访问配置时清理历史密码字段及旧账号列表，页面 preload 会清理旧助手密码键；磁盘备份及未访问的旧配置仍需单独处理。原版保存的 `sgsol.rememberedCredentials.v2`、`sgsol.rememberedCredentials.v2.4399`、共享 JSON 的 `credentials` / `credentialsByScope`、旧 `userlist` 可能仍包含密码。清理前需确认实际安装位置；不要分享这些文件。
- 新源码尚未构建，也没有替换已安装的微端或油猴脚本，修改不会自动保护旧安装。
